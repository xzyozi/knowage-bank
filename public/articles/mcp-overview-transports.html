MCPの概要と主要なトランスポート（stdio, sse）の違い

作成日: 2026年6月15日

Model Context Protocol (MCP) は、AIアプリケーションを外部データやツールへ接続するための標準化されたオープンプロトコルです。JSON-RPC 2.0を基盤とし、ローカル向けの「stdio」とネットワーク向けの「SSE/Streamable HTTP」という主要なトランスポート方式を提供します。このプロトコルの採用により、開発者は各モデルごとに個別の統合を行う必要がなくなり、拡張性の高いシステム構築が可能になります。

簡潔なQ&A

Q. MCPとは何ですか？
A. AIアプリケーションと外部ツールやデータソースを接続するための標準化されたオープンプロトコルで、モデル数とツール数の組み合わせによる実装の複雑さ（N×M問題）を解消します。
Q. stdioとSSE/Streamable HTTPの主な違いは何ですか？
A. stdioはローカル環境でのプロセス間通信に最適化されており、低レイテンシでシンプルな実装が特徴です。一方、SSE/Streamable HTTPはネットワークを介したリモート連携に適しており、高いスケーラビリティとファイアウォールへの対応を備えています。

MCPの基本概念と目的

MCPはAIモデルが学習データの範囲を超えた最新情報の取得や外部システムへの操作を行えるようにするための共通規格です。2024年11月にAnthropic社によって公開されました。

従来の「N×M問題」を解決するため、接続の作法を共通化することで、ツール提供側は一度の構築で複数のホストに対応でき、利用側もツールの差し替えや組み合わせが容易になる「AIアプリのUSB-C」のような役割を果たします。

システムアーキテクチャ

MCPはクライアント・サーバーモデルに基づいており、生成AIを搭載したアプリケーション（MCPホスト）、通信を仲介するコンポーネント（MCPクライアント）、および外部システムに接続してデータを変換提供するプログラム（MCPサーバー）の3つで構成されます。

提供される主要機能

MCPサーバーは、外部システムに対する「操作」を実行するツール (Tools)、情報取得を行うリソース (Resources)、および再利用可能なテンプレートを提供するプロンプト (Prompts) の3つの機能をAIに提供します。

トランスポート方式の比較と技術的差異

MCPはプロトコル層（JSON-RPC 2.0）とトランスポート層を分離しており、物理的な運搬手段として主に「stdio」と「SSE/Streamable HTTP」が存在します。

stdio (標準入出力)

Unixパイプや子プロセスを使用し、標準入力（stdin）と標準出力（stdout）を介して通信を行います。実装がシンプルでレイテンシが非常に低い（5〜15ms）のがメリットですが、ローカル環境に限定され同時接続数は1つに制限されるため水平スケーラビリティには向きません。

SSE (Server-Sent Events) / Streamable HTTP

HTTPプロトコル上で動作し、サーバーからクライアントへ一方向のストリーミングを行います。ファイアウォールやプロキシとの互換性が高く、コンテナやKubernetesを用いた水平スケーリングに対応しています。現在は単一エンドポイントでPOSTとSSEストリームを統合した「Streamable HTTP」が推奨されています。

実装における選択基準

利用環境と要件に応じて以下の基準でトランスポートを選択します。

stdioを選択する場合

ローカルマシン上のツールやファイルシステムと連携する場合、低レイテンシを最優先し開発効率を重視する場合、またはClaude Desktopなどの主要クライアントとの標準的な統合を行う場合に適しています。

SSE / Streamable HTTPを選択する場合

クラウド環境（AWS Lambda, Cloud Run等）やコンテナ環境で運用する場合、複数のクライアントから同時に接続を受け付ける必要がある場合、またはファイアウォール越えのネットワーク経由でのアクセスが必要な場合に適しています。

要点

この記事の要点は以下の通りです。

  • MCPはAIアプリと外部ツールを繋ぐ標準プロトコルであり、N×M問題（接続の複雑化）を解消する。
  • stdioはローカルでの高速・シンプルな連携に最適で、SSE/Streamable HTTPはリモート環境でのスケーラブルな運用に適している。
  • MCPサーバーはツール(Tools)、リソース(Resources)、プロンプト(Prompts)の3つの主要機能をAIに提供する。
