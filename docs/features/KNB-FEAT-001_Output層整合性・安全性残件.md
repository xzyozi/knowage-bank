# KNB-FEAT-001 Output層整合性・安全性改善 機能残件

## 1. 目的と管理境界
本書はOutput層の未実装機能だけを管理する。文書更新は`KNB-PM-001`、実装済み機能は`archive/KNB-FEAT-001_Output層基本実装_完了.md`を正本とする。

## 2. アクティブタスク
| ID      | 優先度 |  状態  | 機能                                    | 完了条件                                                                                                                                             |
| :------ | :----: | :----: | :-------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| FEAT-01 |   P0   | 未着手 | index原子的書込み・保存後検証・失敗補償 | `public/index.html`を既存indexを壊さず保存し、リンク・タイトル・日付・重複を検証し、失敗を状態へ記録できる。                                         |
| FEAT-02 |   P0   | 未着手 | 記事JSON入力・修復経路の撤去            | Issue同期および記事生成の外部入力をMarkdownへ統一し、`repair_truncated_json`と旧JSON生成・修復を削除する。JSON状態・設定ファイルの読込みは維持する。 |

## 3. 依存・運用制約
- FEAT-01を先行し、FEAT-04はFEAT-01〜03の契約を対象とする。
- #11/#13は`failed`を維持し、再試行は失敗理由を解消した後の明示承認時だけ実施する。
- 外部LLM、Deep Research、GitHub APIを使う結合実行は、テスト用設定と明示承認がある場合だけ実施する。
